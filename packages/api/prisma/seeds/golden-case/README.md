# 企业网关鉴权开发 (Enterprise Gateway Authentication)

## 任务背景

在企业级微服务架构中，API 网关负责拦截所有外部请求并进行鉴权。目前我们的基础网关中有一个 JWT 校验中间件，用于验证请求头中的 `Authorization` token。

## 你的任务

在测试环节，安全团队发现目前的网关可以通过**伪造的 Token**直接绕过鉴权，这是一个极高危的安全漏洞。

请查看 `index.js` 中的 `authMiddleware` 实现：

1. 找出代码中存在的安全隐患。
2. 修复该漏洞，确保只有通过正确的 `JWT_SECRET` 签名的 Token 才能被网关接受。

## 提示

- JWT 的核心在于“签名验证”，仅仅“解码”是不够的。
- 请查阅 `jsonwebtoken` 库的官方文档。

## 验收标准

- 未携带 Token 的请求应返回 401 状态码。
- 携带合法 Token 的请求可以正常通过并返回 200 状态码。
- 携带伪造 Token（签名不匹配）的请求必须被拦截，并返回 401 或 403 状态码。
